# You

## Обновление 0.2

Добавлены **20 функций удобства**: восстановление сессии, именованные наборы,
закрепление/дублирование/звук вкладок, групповое закрытие, поиск вкладок, список закрытых,
перенос без перезагрузки, боковая панель, редактор и импорт/экспорт закладок,
подсказки адреса и масштаб для сайтов. Подробности: **[NEW-FEATURES.md](NEW-FEATURES.md)**.

**Меню → Каталог 500 возможностей** содержит все 500 описаний и экспорт в Markdown:
20 отмечены «Готово», остальные 480 — план. Это не заявление о реализации всех 500.

Настоящий настольный браузер для Linux: **GTK4 + libadwaita + WebKitGTK**.
Сайты открываются браузерным движком прямо в приложении, не в iframe и не во внешнем Chrome.
Проект со счётчиком упражнений не изменён и находится вне этой папки.

## Запуск

Перед запуском установите системные зависимости из раздела в конце инструкции. Node.js и pip не нужны.

```sh
cd You-0.2
./run.sh
```

Можно сразу открыть сайт или приватное окно:

```sh
./run.sh https://ru.wikipedia.org
./run.sh --private
```

Добавить You в меню приложений:

```sh
python3 install_launcher.py
```

Браузер по умолчанию **не меняется**. Если переместить папку проекта, ярлык нужно
обновить вручную: в нём используется полный путь к `run.sh`.

## Что работает

- Вкладки, закрытие и повторное открытие закрытой вкладки.
- Адресная строка: адреса, локальные сайты, русские домены и поисковые запросы.
- Назад, вперёд, обновление, остановка загрузки; ссылки открываются внутри You.
- Новая вкладка с поиском, быстрыми ссылками и сохранёнными закладками.
- Выбор DuckDuckGo, Google или Яндекса в настройках.
- Закладки и поиск по ним; история посещений и её очистка с подтверждением.
- Загрузки в системную папку загрузок: прогресс, отмена, открытие готового файла.
  Существующие файлы не заменяются — подбирается новое имя.
- Приватные окна с отдельными cookies и данными сайтов в памяти.
- Поиск по странице, масштаб, полный экран, открытие локальных файлов.
- Запрос подтверждения доступа к камере, микрофону, местоположению и буферу обмена.
- Проверка HTTPS-сертификатов; ошибочные сертификаты не обходятся автоматически.
- JavaScript, CSS, формы и cookies обрабатываются WebKitGTK.

## Профиль и приватность

Обычный профиль: `~/.local/share/you-browser/` (или `$XDG_DATA_HOME/you-browser/`).
Закладки, история и настройки находятся в `browser.sqlite3`; cookies и данные сайтов
хранятся в этом же отдельном профиле. You не читает профили других браузеров.

В приватном окне история не записывается, cookies и данные сайтов изолированы
в оперативной памяти и не сохраняются после закрытия. **Это не анонимизация**:
сайты и провайдер всё ещё видят сетевые обращения. Скачанные файлы и закладки,
добавленные вручную в приватном окне, остаются на диске.

На стартовой странице нет удалённых картинок, аналитики или автоматических запросов
к поисковику. Сеть используется, когда открывается сайт или отправляется запрос поиска.

## Ограничения первой версии

Это небольшое самостоятельное приложение на системном движке, не копия Chrome.
Нет расширений Chrome, синхронизации, менеджера паролей и DRM/Widevine. Восстановление
сессии возвращает адреса и свойства обычных вкладок, но не формы или JavaScript-состояние.
При включённом восстановлении прошлые сайты загружаются автоматически при старте;
автооткрытие отключается в настройках. Приватные окна не сохраняются.
Некоторые провайдеры авторизации могут запрещать вход
во встроенные WebKit-приложения. Поддержка видео и кодеков зависит от системного GStreamer.
Разрешения запрашиваются для текущей страницы, без постоянного списка исключений.

**Обновляйте WebKitGTK и систему:** приложение использует установленную в Linux версию
движка, а не загружает собственные обновления безопасности. Защиту sandbox и проверку
сертификатов приложение не отключает. Для локального самоподписанного HTTPS-сайта
нужен сертификат, которому доверяет система.

## Проверки

```sh
python3 -m unittest discover -s tests -v
```

Проверяются адреса, хранение данных, настоящая загрузка страниц, JavaScript, вкладки,
навигация, приватность cookies/истории и скачивание файла через WebKit.
GUI-тестам требуется работающий графический сеанс. Для тестирования есть отдельный профиль:

```sh
./run.sh --profile /путь/к/отдельному/профилю
```

## Зависимости на другом компьютере

Python 3.10+, системный PyGObject (`gi`), GTK 4.10+, libadwaita 1.5+, WebKitGTK API 6.0.
Например, в Debian/Ubuntu соответствующие пакеты: `python3-gi`, `gir1.2-gtk-4.0`,
`gir1.2-adw-1`, `gir1.2-webkit-6.0`. Нужны достаточно новые версии этих пакетов.
Запуск через `run.sh` использует системный `/usr/bin/python3`, чтобы видеть GI-библиотеки.
